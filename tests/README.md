# Engine tests

From the repo root (Python 3.9+, standard library only, offline):

```sh
python3 -m unittest discover -s tests -v
```

What runs:

- `test_align.py`: spoken numbers ↔ digits; the global alignment's guarantees (starts rise, no two words on one start, every word inside its own line's window, ≥ 0.08 s, never into the next line) on real and adversarial transcripts (Whisper-style early line starts, late line ends, a line the ASR missed, unsorted ASR, 150 seeded random jitters); an ASR word without an `end` (it ends at the next start); equal starts from scrambled ASR (a 1 ms step, the round-3 fuzz case, and 120 seeded wild-fuzz trials with no zero-length cue); collapsed ASR instants (episode 1's Parakeet transcript with three 6-word runs on one timestamp, as a verifier made it; Whisper's near-equal starts; a collapse at a line end; two collapsed instants a tenth of a second apart) spread by character length to the next distinct start, while the real Parakeet transcripts are untouched; episode 1's script against its real Parakeet transcript (`fixtures/example/audio/`, text only), compared with the earlier per-line alignment (`words-per-line.json`: at most 3 words moved, each by ≤ 0.011 s); and the worked example (`references/example`) voiced by `voice.py`, with real `transcript-whisper.json` and `transcript-parakeet.json` of the same narration (`fixtures/worked-example/audio/`, from `npx -y hyperframes@0.8.147 transcribe narration.wav --engine whisper --model small.en --json` and `--engine parakeet`): Whisper passes the caption gate and agrees with Parakeet.
- `test_captions.py`: cue limits, scene cuts (a cue's lead never crosses the cut that opens its scene), the display map (word boundaries only), relief (a cue over `max_cps` borrows its neighbours' slack: ≤ 0.3 s earlier, ≤ 0.1 s of the next cue, never across a cut, a no-op without violations; through a fast neighbour to the slow cue beyond it; as a last resort ≤ 0.5 s earlier), the reading-speed split (words spoken faster than `max_cps` − 2 that relief cannot bring to it get up to 4 cues with boundaries placed by reading speed; no change on the real fixtures), the 0.5 s floor where the scene allows (a shorter cue merges with a neighbour of its scene, else starts earlier, back to its own scene cut; a one-word scene too short keeps the whole scene), cue starts that never coincide (two cues opening on one cut), the dynamic-programming split (identical to trying every split on 250 seeded clauses; a 45- and a 60-word unpunctuated clause in under 1 s), a seeded jitter regression (the worked example's Whisper transcript at σ 0.05 and 0.1 s and its Parakeet transcript at 0.2 s pass the gate in all trials; episode 1's at 0.2 s in all but at most 1 of 60), `--strict`.
- `test_scene_words.py`: slicing `words.json` into per-scene local times, and the scene/cut desync check.
- `test_capture.py`: `capture.sh` on `fixtures/capture/brief.md` with a stub `npx` and a minimal `PATH`, so the system's own `grep` runs (BSD on macOS, GNU on Linux). Covers stable ids, selected-first ordering, `SVS_MAX_SOURCES`, reuse and failure exits, `--help`, and the `EVIDENCE.md` note that replaces HyperFrames' `AGENTS.md`/`CLAUDE.md`/`.cursorrules` in every capture.
- `test_episode_tools.py`: the disclosure rule (fixed parts plus one generated segment from `reviewed_by`; none of 85 free-text phrasings, the 33 an earlier blocklist dropped, the 51 a verifier found it kept and 3 harmless ones, reaches the line from the legacy `disclosure` field, each ignored with a warning that names `credits`, while a legacy segment that is an allowlisted credit moves to the Credits line; `reviewed_by` must be a person's name in Latin letters, never a separator-like letter such as `ꞏ ǀ ː` or another script), `credits` (allowlisted labels, own "Credits" line, a warning for one that claims a review, at most 3 of ≤ 64 characters on the close card then "+N more"), a `credit` switch holding credits text (read as `credits`, loudly), on the companion page, the `fill_scenes.py` close and the close template, the `new_episode.py` starter (`credits: []`, no `disclosure`) and the `deliver.py` gate, the one-thing question split when the highlight opens the question, `deliver.py`'s `transcript.md` display forms, and the paths `new_episode.py` prints.
- `test_engine_misc.py`: the config contract, `voice.py --asr`, `setup.sh --no-skills` (dry run) and doctor's `hf skills` line (WARN, not FAIL, without the core skills; offline with a stub `npx`), exact npm pins, no hardcoded HyperFrames or GSAP version and no personal paths in any engine or demo file, UTF-8 `open()`, shell syntax, every HyperFrames `snapshot` call passing `--describe false`, and CLI smoke tests (`--help` exits 0 on every Python, shell, Node and Swift tool, demo included; `doctor.mjs --help` must not run the checks).
- `test_templates.py`: every HyperFrames command in a shipped file pinned to `engine/config.json` (every Markdown file except under `fixtures/`, and every text file of the skill: docstrings, usage strings, comments; no unversioned npx call, no other version, no bare CLI command without npx), the episode project template (every `hyperframes@` pin in `templates/project/` equals `engine/config.json`, `npm run snapshot` passes `--describe false`, `npm run check` passes `--strict`), every documented `npx … snapshot` command passing `--describe false`, SKILL.md stage 0 running doctor, asking before setup and offering `--no-skills`, stage 10 stopping the preview, and the receipt template's pull-back dimmer (also through `demo.fill_template`).

Some tests skip themselves when a tool is missing. The `loudfix.sh` and `deliver.py` tests need `ffmpeg`; the `setup.sh --no-skills` and doctor tests need Node ≥ 22.12; the `ocr-locate.swift` test needs `swift` on macOS. The `receipt.mjs` render tests need `node`, `puppeteer-core` (`engine/setup.sh`) and a local Chrome; they render a saved `file://` page and use no network. To point them at a non-default install, set `SVS_HOME`.
