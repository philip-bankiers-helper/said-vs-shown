# Said vs. Shown episode: HyperFrames project

This folder is one episode's video project, built by the `said-vs-shown` agent skill. Make changes through that skill's stages (ask your agent to use the said-vs-shown skill), not by hand. The skill's files (`SKILL.md`, `engine/`, `templates/`, `references/`) live where it was installed: usually `.agents/skills/said-vs-shown`, `~/.agents/skills/said-vs-shown`, `~/.claude/skills/said-vs-shown` or a Claude Code plugin cache (`npx skills ls` shows where).

- Design truth: `frame.md`. Data contract: the skill's `references/project-layout.md`. Scene kinds: the skill's `references/scenes.md`.
- Facts on screen come from `../edit/episode.json` and `../ledger/`; every claim traces to `../ledger/claims.json`.
- `index.html` is generated by the skill's `engine/assemble.py`. Never hand-edit it.
- Scenes live in `compositions/NN-<scene>.html`. The squeeze, payoff, one-thing and close are filled by `engine/fill_scenes.py`; boards and boundaries come from `engine/board.py` / `engine/boundary.py`; receipt scenes are authored from the skill's `templates/scenes/receipt.html`.
- HyperFrames is pinned in `package.json`: `npm run check`, `npm run snapshot` and `npm run render` use that version. For the composition contract, read the `hyperframes-core` skill (in `~/.claude/skills/` or `~/.agents/skills/`). If it is missing, `npx hyperframes skills update hyperframes-core` installs it (it changes your agents' global skill folders, so ask first), or read `npx hyperframes docs compositions`.
- `BRIEF.md` is reference material for HyperFrames skills; it does not route this project to a HyperFrames workflow.
